# Git-first portable Tribunal skill

## Why
Review work must survive an agent session, reuse one public skill, preserve unresolved conditions and resume safely across hosts. A structural local score is not a semantic acceptance decision.

## What changes
Add a root Agent Skill and dependency-free Git state/gate CLI alongside the existing API. Parent repositories pin the public skill as a submodule. An explicit host entry/heartbeat discovers selected tickets/issues. Git commits on a dedicated private ref retain claims, evidence metadata, reviews and conditions. Regenerable Hans/OpenSpec projections are not a second authority.

## Scope
Implemented: discovery, idempotent intake, ordinary-push concurrency control, leases/fences, evidence integrity, bounded conditional re-review, receipts and safe projections. No provider lock-in.

## Non-goals
A new agent orchestrator, unattended host scheduler, production action authorization, automatic code execution from issue bodies, new research backend, authenticated judge identity, universal browser automation, replacing the legacy API or publishing private histories.
